# SQL Case Study - Data Bank Analysis

This project contains the SQL solutions for Case Study #4 (Data Bank) from the 8 Week SQL Challenge. It explores distributed banking nodes and customer transaction patterns.

## Database Schema
The database consists of three primary tables:
* `regions`: Mapping of region nodes globally.
* `customer_nodes`: Allocation details of customers to specific storage systems.
* `customer_transactions`: Historical ledger data of deposits, withdrawals, and purchases.

## How to Run
You can execute these scripts using PostgreSQL or by loading the schema and solution files into any SQL editor connected to the target database instance.
