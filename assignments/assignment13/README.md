# Assignment 13

NumPy and Matplotlib practice scripts for array operations, linear algebra, and semester result comparison.

## Files

- `q1.py`: replace `NaN` values and transpose a 2D array
- `q2.py`: move axes in a 3D array
- `q3.py`: fill `NaN` values with column averages
- `q4.py`: replace negative values with zero
- `q5.py`: array averaging and summary statistics
- `q6.py`: solve a linear system with two methods
- `q7.py`: save a semester comparison chart

## Run

```bash
python q6.py
python q7.py
```
